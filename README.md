# Financial Crime AI Lab

> Building practical AI, agentic workflow and financial crime intelligence capabilities through hands-on experimentation and prototype development.

## Overview

The Financial Crime AI Lab is a practical learning and experimentation repository focused on applying Artificial Intelligence to Financial Crime, AML, Sanctions, Compliance and Intelligence-led investigations.

The purpose of this repository is to combine Financial Crime domain expertise with emerging AI technologies and develop practical solutions that support investigators, analysts, compliance teams and transformation programmes.

This repository will document learning, experimentation, prototypes and proof-of-concepts across AI, automation, analytics and financial crime transformation.

## Active Projects

### Transaction Monitoring Rule Tuning

[`projects/tm-rule-tuning`](projects/tm-rule-tuning/) — a 10-week practical
curriculum in advanced transaction monitoring rule tuning, plus `tmtuning`, the
reusable Python toolkit the exercises are built on.

Covers backtest design, evidence-led threshold optimisation, alert-volume and
risk-yield curves, segment-specific calibration, above/below-the-line testing,
drift detection, champion-versus-challenger comparison, and the production of
validation-ready tuning papers.
