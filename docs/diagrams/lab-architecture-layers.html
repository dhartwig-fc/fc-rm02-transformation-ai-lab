Financial Crime AI Lab · Target architecture

Build the capability once, reuse it everywhere

Five layers from the tools that build the lab to the screens investigators use. Financial crime expertise lives in the capability layer and is exposed through MCP and Skills, so front-ends and models can change without rewriting it.

THE HEADLINE

Coral marks where the value lives

Front-ends and models are interchangeable parts. The capability layer (sanctions lookup, typology knowledge, triage and SAR drafting) is the financial crime know-how. Build it once, and every screen above can use it.

Status today

  • Build: in place, with plugins audited and pinned
  • Models: local Ollama stack configured, not yet run
  • Guardrails: gate and prompt check, 121 tests
  • Capability: first Skill and MCP server next

Why MCP in the middle

Claude Code, Open WebUI, n8n and Dify all speak MCP. If a front-end is replaced next year, the capabilities move across unchanged, like a standard docking port.
